# chateaux shop: подключение сайта к боту

## Что это даёт
Когда человек открывает магазин из твоего бота, Telegram передаёт сайту подпись («initData»). Сервер проверяет её секретным токеном бота. Подделать её нельзя, поэтому сервер **точно знает**, кто это: Telegram ID, @username, имя. Отсюда всё остальное:
- заказам присваиваются номера по порядку: №1, №2, №3 (и клиентам Room №1, №2, №3);
- ты видишь заказы в Telegram: кто заказал, @username, номер заказа, сумма. Под каждым заказом кнопки «Paid / Delivered / Cancel»;
- покупатель видит свои заказы и их статусы и в мини-приложении (кружок профиля), и в боте (команда /orders), и получает уведомление, когда ты меняешь статус;
- цены, скидки и промокоды считает сервер, а не страница, поэтому их нельзя подменить.

## Какие файлы нужны (все 4 в одной папке)
| файл | что это |
|---|---|
| `index.html` | сайт (мини-приложение) |
| `server.py` | сервер и бот |
| `core.py` | логика: проверка подписи, цены, база заказов |
| `requirements.txt` | список библиотек |

`.env.example` загружать никуда не надо: это просто подсказка, какие настройки вписать на хостинге.

## Как запустить, по шагам
1. **Свой Telegram ID.** Напиши боту @userinfobot, он пришлёт число. Это твой `ADMIN_IDS`.
2. **GitHub.** Создай репозиторий и через «Add file → Upload files» загрузи 4 файла из таблицы.
3. **Хостинг для Python-сервиса.** Подойдёт любой, который (а) работает постоянно и не засыпает, (б) даёт постоянный диск или том для базы, (в) выдаёт адрес с https. Варианты: Render, Railway, Fly.io или обычный VPS. Условия и цены у них меняются, поэтому проверь перед выбором.
   - Команда установки: `pip install -r requirements.txt`
   - Команда запуска: `uvicorn server:app --host 0.0.0.0 --port $PORT`
   - Запускай **один** экземпляр (бот работает в режиме опроса, два экземпляра будут мешать друг другу).
4. **Переменные окружения** (в настройках хостинга, не в файлах!):
   - `BOT_TOKEN` токен бота от @BotFather (никому не показывай)
   - `WEBAPP_URL` адрес, который выдал хостинг, например `https://moy-shop.onrender.com`
   - `ADMIN_IDS` твой Telegram ID (если вас несколько, через запятую)
   - `DB_PATH` путь к файлу базы на постоянном диске, например `/data/shop.db`
5. **Включи связь на сайте.** В `index.html` найди строку `var API = null;` и замени на `var API = "";` (сервер сам отдаёт сайт, поэтому адрес пустой). Загрузи обновлённый файл в репозиторий.
6. **Проверка.** Открой бота, нажми `/start`, затем «Open shop». В профиле должна появиться надпись «Verified with Telegram ✓». Сделай тестовый заказ: тебе в Telegram придёт сообщение с кнопками.

Меню-кнопка «Shop» в боте ставится автоматически при запуске сервера.

## Команды бота
- Покупатель: `/start`, `/orders` (его последние заказы)
- Основатель (только `ADMIN_IDS`): `/all` (последние 20 заказов), `/order 12` (заказ №12 с кнопками)

## Важно знать
- **Цены лежат в двух местах.** Настоящие цены, скидки (`TIERS`) и промокоды (`PROMOS`) находятся в `core.py` (список `CATALOG`). В `index.html` цены нужны только для показа. Меняешь цену: меняй в обоих файлах, иначе на сайте будет одно, а сервер посчитает другое.
- **Оплата пока ручная**, как и раньше: покупатель платит Stars-подарками или на карту, ты нажимаешь «Paid» в боте. Antilopay подключается следующим шагом через этот же сервер.
- **Вне Telegram** (обычный браузер) страница по-прежнему работает «сама по себе»: подтвердить аккаунт можно только изнутри Telegram. Для обычного сайта есть проверка Telegram Login Widget (`verify_login_widget` в `core.py`), но для неё нужно задать домен у @BotFather командой `/setdomain` и добавить кнопку на сайт.
- Токен бота нельзя выкладывать на GitHub или вставлять в `index.html`. Если он утёк, перевыпусти его у @BotFather.

## Что уже защищено (проверка кода)
- Личность берётся только из подписи Telegram, номер и имя от страницы не принимаются на веру.
- Цены, скидки и промокоды считает сервер. Страница присылает только «какие страны и сколько штук».
- Подпись для оформления заказа должна быть свежей (не старше часа): нужно заново открыть мини-приложение.
- Лимиты: не больше 5 неоплаченных заказов у одного человека; не больше 10 неверных промокодов в час; двойное нажатие «оплатил» не создаёт второй заказ и не шлёт тебе второе уведомление.
- Смену статуса может нажать только Telegram ID из `ADMIN_IDS`. Без `ADMIN_IDS` сервер не запустится.
- Все запросы к базе параметризованы, тексты в сообщениях бота экранируются, CORS открыт только для адреса сайта.

## Что остаётся на тебе
- Реквизиты карты лежат прямо в `index.html`, их может скопировать любой, кто откроет код страницы. Следующий шаг: показывать их только после создания заказа, в сообщении бота.
- Размер запросов ограничивает хостинг (у серверов это обычно есть в настройках); в коде отдельного ограничения нет.
- Лимиты хранятся в памяти и сбрасываются при перезапуске сервера.
- Делай резервную копию файла базы (`DB_PATH`).
- Когда пойдут реальные деньги, особенно через Antilopay, стоит показать код живому специалисту по безопасности. Мой разбор не заменяет полноценный аудит.
